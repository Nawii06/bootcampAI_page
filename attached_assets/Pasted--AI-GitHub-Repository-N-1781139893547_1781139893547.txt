당신은 첨단산업 인재양성 부트캠프(AI) 사업단 홈페이지 및 통합관리 포털의 프로토타입을 구현하는 시니어 풀스택 개발자입니다.

대상 GitHub Repository:

현재 repo는 홈페이지 소스 저장소가 아니라, 국립한국교통대학교 첨단산업 인재양성 부트캠프(AI) 사업의 운영관리 자료 저장소입니다.
README와 각 폴더의 Markdown/CSV/JSON 자료를 검토하여, 현행 구조를 홈페이지와 내부관리시스템의 정보구조로 전환하는 Replit 실행형 웹 프로토타입을 작성하세요.

중요:

1. 구현 목표
────────────────────────

다음 요구사항을 반영한 “부트캠프 통합 홈페이지·포털 프로토타입”을 구현하세요.

핵심 목적:
1) 홈페이지를 통한 사업 자체 홍보
2) 홈페이지를 활용한 학생 프로그램 신청
3) 홈페이지를 통한 유관기관 정보 확인 및 연계
4) 기존 학교 정보시스템과의 SSO 토큰 연결을 위한 구조 설계
5) 사업 성과관리시스템 구성
6) 사업 예산 집행현황 입력 시스템 및 예산 변경내역 관리
7) 학생 신청, 교육과정 운영, 참여기업, 예산, 증빙, 성과지표가 연결되는 성과관리 구조 구현

프로토타입은 “공개 홈페이지 + 학생 포털 + 기업/유관기관 포털 + 관리자 시스템”의 4개 영역으로 구성하세요.

- Styling: CSS Modules 또는 일반 CSS. Tailwind는 사용하지 않아도 됩니다.

10. 실제 구축 전 검토사항 문서화

- 공개 홈페이지와 관리자 시스템의 권한 분리 필요
- 로그 관리 및 접근권한 관리 필요

12. 작업 방식
────────────────────────

1. 먼저 repo 구조를 확인하세요.
2. 기존 운영관리 문서와 데이터 구조를 훼손하지 마세요.
3. 홈페이지 프로토타입은 새 폴더에 구성하거나, 기존 repo 루트가 웹앱 구조로 전환되어도 기존 문서 폴더는 유지하세요.
4. 기존 Markdown/CSV 파일은 삭제하지 마세요.
5. 필요한 경우 app 또는 prototype-web 폴더를 생성하세요.
6. 작업 완료 후 변경 파일 목록과 실행 방법을 요약하세요.
7. 테스트 또는 typecheck 결과를 요약하세요.
8. 실제 연동이 필요한 부분은 TODO 주석과 문서로 남기세요.

권장 구현 위치:
- prototype-web/

단, Replit에서 루트 실행이 더 안정적이면 루트에 package.json을 두고 기존 문서 폴더를 유지하는 방식도 허용합니다.
